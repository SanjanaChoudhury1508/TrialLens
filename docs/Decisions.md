# Engineering Decisions

This document records important architectural and technical decisions made throughout the development of TrialLens.

Recording decisions helps maintain consistency as the project grows.

---

## Decision Log

### Initial Technology Stack

- Frontend: Next.js
- Backend: FastAPI
- Database: PostgreSQL
- Vector Store: pgvector
- Orchestration: LangGraph
- Deployment: Docker

Reason:

Selected to support a modular, production-oriented AI application.
