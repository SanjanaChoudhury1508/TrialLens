# Database Design

## Overview

TrialLens uses PostgreSQL as the primary database.

Vector embeddings will be stored using the pgvector extension.

---

## Planned Data

The database will store:

- Clinical trial metadata
- PDF metadata
- Parsed document text
- Extracted tables
- Embeddings
- Agent logs
- Evaluation results

---

## Planned Technologies

- PostgreSQL
- pgvector
- SQLAlchemy

---

## Status

Database schema has not yet been finalized.
